GS 最终设计 (GS-G2): 让枚举相位 + 运动级打分发挥到最好 (2026-10-12, 设计稿, 未实现)
用户令: "给出最终的设计, 你可以信息不对称, 现在追求让 gs 最好的设计发挥效果。" 只用 5-3-1 标量奖励, 不考虑 envelope。
依据: DUBLIN18H_GS_ABLATION §6-§21, GRID1X1_STATE_ABLATION_2026-10-12, 本日设计讨论的六条缺陷 (τ 在半切换下错误 / 最大绿可被绕过 / 残差保证只是表达力 / 11h 证据有混杂 / 残差可能吃掉泛化 / 选点种子泄漏)。

§0 GS 要赢的三件事 (证据)
  · 不会保持: 学习型 GS 切换接近上限 360/h (309), 半切换占 27-55%。
  · 绿灯给得晚: 压力型等绿 9.2 vs 8STD 7.2 s; 逐运动打分只看检测区内、且只看本槽。
  · 被空方向牵着走: since_green 左右 40-55% 决策, 值多在无车槽。
  另: 都柏林受控进口车道很短 (中位 77 m, p10 15 m, p90 216 m) —— 车道内的车辆数对 "下一股车队何时到" 几乎没有信息, 提前切换需要看上游。

§1 观测 (允许比 8STD 多; 论文中声明为 GS 的信息优势)
  每运动槽 i:
    a. is_green
    b. φ 5 优先级桶 × (车辆数, 排队数, 平均等待 log, 最长等待 log)       —— 加 max_awt: 只在有车时非零, 是 since_green 的 "无空方向偏置" 替代
    c. ψ 下游 5 桶 × (车辆数, 排队数), lane_occ
    d. 本运动连续放行时长 g_i (真实绿灯, 不含黄灯, 跨相位累加), log(1+s)/log(1+600)   —— 给截断代价用; 对数刻度避免常绿运动顶上限
    e. 到达剖面 (新): 沿车道图向上游回溯 (含前驱车道), 按到停车线距离分 3 段 [0,50) [50,120) [120,250) m 的车辆数 (按优先级加权) 与平均速度 —— "下一股车队何时到"
    f. 上游路口对本进口的放行状态 (新, 若上游是 RL 路口): 上游放向本进口的运动此刻是否绿、已绿多久 —— 协调信号, 预告车队
  路口级: τ (相位已持续/100) 只给最大绿规则用, 不进网络 (半切换下语义错误, 见 §6-1)。
  不用: since_green (被 max_awt 与到达剖面取代), 压力乘性骨架。

§2 网络 GS-G2 (共享参数, 任意路口、任意相位数)
  ① 运动编码      e_i = Enc([x_i, E_id(i)])                 身份嵌入 8 维
  ② 关系注意力 ×1  e_i ← e_i + Σ_j Attn(e_i, e_j | rel_ij)    rel = 同相位/兼容/合流冲突/交叉冲突 作注意力偏置
  ③ 路口上下文     c = [mean, max]_i e_i
  ④ 上下文化       ê_i = MLP([e_i, c])
  对每个候选相位 k (cur = 当前相位, 由 is_green 与 pm 匹配得到):
  ⑤ Q(s,k) =  Σ_{i∈k} g(ê_i)                         服务分
            + Q_sup(k)                                对决压制分 (FRAP 原有, 7 月判定为承重墙)
            − Σ_{i∈cur\k} κ_cut(ê_i, g_i)             截断代价: 读被截断运动自己的放行时长与车流
            − Σ_{i∈k\cur} κ_new(ê_i)                  起动代价: 黄灯 + 起动损失
            + b([mean_{i∈k} ê_i, c])                  相位残差 (16 隐层, 末层零初始化)
     κ 用 softplus, 初始 ≈ 0 → 训练起点与组合式 FRAP 等价。
  参数量约 1.5-2.5 万 (8STD 2.7-4.4 万)。
  去掉 ②③④⑤-κ⑤-b 与 E_id → 原 FRAP; 消融逐项可归因。

§3 规则 (两臂共用, 进协议修订)
  · 最短绿: 环境已有 (5 s + 2 s 黄灯)。
  · 按运动的最大绿: 任一运动连续放行 ≥ 90 s 且有冲突运动有车 → 屏蔽所有仍放行它的相位 (半切换绕不过去)。
  · 按运动的饿死保护: 任一有车运动连续红灯 ≥ 120 s → 屏蔽所有不放行它的相位。
  · 需求门控: 放绿运动上无车 (含到达剖面 0-50 m 段) 的相位屏蔽。
  · 掩码同时进 TD 目标 (next_mask)。

§4 训练 (GS 专属的改进, 允许不对称)
  · n-step 回报 (n=3, 15 s): 截断车队的代价要过几步才在等待里显现, 1 步 TD 难以把它归到切换动作上。
  · 双 DQN, Huber, 梯度裁剪 1.0, 目标网每集同步, 都柏林 TD 钳位 [−50, 0] (与现配方同)。
  · 回放按 "有公交/救护车在场" 分层保底采样 (每批 ≥ 10%): 稀疏优先级类的梯度保障 (7 月多头失败的教训)。
  · 菜单清理 (开关, 先做消融): 合并只差一个低流量运动且都含主流向的相位。
  · 选点与测试种子分离: 训练期评估用种子 200-202 选 best, 测试用 123-132。
  · 每臂 3 个训练种子。

§5 预期与可证伪判据
  1x1: 打平 327 (信息对等时两种头已打平; 1x1 输固定周期是场景性质)。到达剖面在 1x1 (单路口、长车道) 增益有限。
  11h/02h: 胜 342 (8STD 统一状态); 若 342 已追平 211, 胜出全靠 §1-e/f 与 §2。
  18h: 胜 334; 判据 = 切换次数与有效相位数接近或低于 8STD, 到达遇绿 ≥ 8STD, 停车次数 ≤ 8STD, 分车类 J 与优先级排序不劣。
  零样本: 留出 4 个路口, GS-G2 可直接部署; 8STD 需模板能装下。
  探针验收: κ_cut 随被截断运动的流动车增加而增大、随其放行时长增加而减小; 置换到达剖面应显著改变提前切换的决策。

§6 已知风险
  1. 到达剖面依赖车道图回溯, 跨非 RL 路口时路径不唯一 → 按转向比例加权或只回溯一层; 先在 1x3 检验。
  2. 上游放行状态 (§1-f) 只对 RL 上游有效, 都柏林约一半进口的上游不是信号 → 特征置 0 + 存在位。
  3. 信息不对称: 论文须报告 "8STD + 同样新增观测" 的对照, 否则胜出无法归因到方法 (8STD 也读得了到达剖面)。
  4. n-step 与掩码目标的交互: 中间步的掩码不进目标, 只有第 n 步的 next_mask 用于取 max。
  5. 残差 b 可能吃掉组合结构 → 留出路口迁移测试为验收条件。

§7 实现顺序 (需批准; 新文件 + 新开关, 旧代码与旧配置逐位不变)
  1. 协议修订 (按运动最大绿 + 饿死保护 + 需求门控 + 虚构信号降级 + 选点种子分离)。
  2. 观测: max_awt (已有字段, 零代码) → 逐运动放行时长 (已有, 换对数刻度开关) → 到达剖面 (新, 车道图回溯) → 上游放行状态 (新)。
  3. 网络 GS-G2 (新文件 gsg2_qnet.py + frap_glue 的 arch 分支) + n-step 回放 + 分层采样。
  4. 1x1 消融 (逐项) → 1x3 (到达剖面与上游状态在这里首次有意义) → 都柏林 11h/18h, 3 种子。
