                            amb旧桶, 零训练) 门 5/5 全过 + J 78.5 —

三、五个机制结论
  1. 65-73 不是微调失败盆地, 是 4-2-1 reward 的 TD 吸引子本身
     (从头训 2000ep 也落在那) — 弱边际契约的 TD 解质量差
     (margin 理论: 421 的 bus-car 边际=1, 金标准 bus 11.0s)。
  2. 5-3-1 强边际母策略是邻近契约的最强起点: 数值换约白拿,
     重排 300ep(总账 2300ep) 超过原生 2000ep — 预训练-微调逻辑。
  3. M1 尺度冲击证伪 (rscale 无效); M2-大小证伪 (20k warmup 无效);
     M3 确认: 残差臂 base 全程冻结完好仍劣化 — 离开起点不需要
     破坏参数, 新约 TD 梯度在起点处即指向劣质吸引子。
  4. v4 赢的原因: 冻"契约无关物理", 放"契约语义" (enc+头) —
     heads-only 冻死 enc 在重排下背 OOD 嵌入不可恢复 (564)。
  5. 构造保底可行 (残差首评逐位=do-nothing) 但锚只减缓不阻止。

六、[09 新增] 复核更正与新发现摘要 (全文见 REVERIFICATION_LEDGER)
  6a 零训练交换的两个变体 (ground truth: exp220 训练用默认表
     {amb:5,bus:4,truck:2,car:1}, 数据证实 l4=bus/l5=amb/l2,l3 全空):
     变体A 双入训练桶 (amb→4=bus旧桶, bus→5=amb旧桶): J351 均值 78.5
       [63.2-104.9], 门 5/5 全过。原榜"~105"即此变体的最差种子。
     变体B 契约值即桶号 (amb→3=处女桶, bus→5; 228d/f 实际起点, 首评
       323.5 逐位吻合): J351 均值 267 [173-324] — amb 在处女桶近乎不可见。
     → 228d 的"桶交换"只有 bus 半边继承了训练桶; amb 半边落进处女桶是
     设计滑坡。正确机制 = 桶身份与契约价格解耦 (obs_priority_source 键
     正为此而生): obs 双入训练桶, reward 按契约定价。
     probe_1x1 无 bug (其表恰为变体A), 但按 cfg 键回退是巧合正确, 已注释。
  6b 228d 起点真相: 处女桶起点零训练 323 → 微调收敛 75.5 (先深跌后
     拉回) — 微调能从坏起点恢复, 但起点本可不坏 (变体A 78.5)。
     待验候选 (需批准): 变体A 起点 + 解耦键 + v4 微调, 有望 J 与门双优。
  6c 351 缺失基线补测: do-nothing J351 均值 60.9 [56.7-66.4] 数值碾压
     全部 351 臂。机制: 母策略 amb 停车≈0 是全部本钱, 重排微调以 amb
     恶化 (+9s×权3≈27) 换 bus 微增益 (−1.2s×权5≈6), 净亏。但 do-nothing
     违 351 排序门 → 双镜头判决 (见 §一)。门判定单集 amb n=1-2 欠功效,
     正式门须窗口化坏率 (E3 前置)。
