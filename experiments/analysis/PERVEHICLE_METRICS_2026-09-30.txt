1. 设计原则
  1.1 方法间比较用 "同一辆车" 配对: 两臂评估用同一种子、同一路由文件, 每辆车 (id 相同) 在两臂下各有一次行程。配对差
      GS − 8STD 把路线、出发时刻、路口构成全部抵消, 只剩控制差异。配对单位 = (车辆, 第 k 个检查点), k = 1..4 (各臂末 4 个
      检查点: Dublin ep650/700/750/800; 1x1 ep1350-1500; 1x3 275 ep4550-4700 / 265 ep3900-4050, 即各自训练末段)。
  1.2 主量 = SUMO tripinfo 的 timeLoss (相对自由流多花的秒数): 1 s 分辨率 (旧 per-visit 停车时间是 5 s 采样, 一次停车最少记 5 s),
      包含减速未停的损失, 对每辆车定义, 与路线长度无关的部分用 "相对时间损失 = timeLoss / (duration − timeLoss)" 表示。
  1.3 跨车类 (优先级是否落实) 不再用聚合的 amb ≤ bus ≤ car 保序门, 改用两种防路线构成的量:
      (a) 同口同 movement 分层比: 只在同一路口、同一连接 (movement) 上比较救护车/公交与小汽车的进口道停车秒, 层内至少 5 辆
          小汽车, 按高优先级类访问量加权; 比值 < 1 = 该类比同路径的小汽车更少停。
      (b) 相对时间损失 (1.2), 跨路线可比。
  1.4 救护车事件指标 (n 小也能按次数解释): 到达绿灯率 (进入进口道时其连接为绿), 无停车通过率, 服务延迟中位 (红灯到达 →
      首次变绿), 单次最大停车。
  1.5 稳健性单列: 完成率 (episode 结束前到达), 锁死次数 (4 个检查点里任一路口进口道均停车 > 100 s 的次数)。
  1.6 统计: 配对差的 95% bootstrap CI (2000 次), GS 更优比例 (剔平局), Wilcoxon 符号秩 p (非零差 ≥ 10 个才算)。
      注意 4 个检查点下同一辆车出现 4 次, 配对样本不独立于车辆, CI 偏窄; 解读时以效应量与方向为主。

2. 与旧表的差别 (为什么值会不一样)
  - 旧 per-visit 停车时间: 只数受控口进口道上速度 < 0.1 的 5 s 采样, 再按车归一到 "每次路口访问"; 新 timeLoss: 全程 (含非受控口、
    路段减速、排队跟车), 1 s 分辩率, 每辆车一个数。所以新表的绝对值更大, 且非受控口的排队 (如 Aungier 合流瓶颈) 会计入。
  - 旧表窗口 = 训练中尾 40 次评估 (40 个不同策略快照); 新表 = 末 4 个保存的检查点 (检查点每 50 集才存一次), 样本少但每次评估
    里每辆车都可用。两表口径不同, 结论方向一致时互相印证, 不一致时以新表 (配对) 为准判断方法差异, 以旧表看训练末段稳定性。

3. 结果 (见 §3.x, 随批量评估完成逐块填入)
  (数值全部取自 figures/main_comparison_pervehicle_2026-09-30_en.json; 18h 两对待训练结束后补跑, 见 §4)

  3.1 1x1 (274 vs 263, ep1350-1500, 每检查点 1176 辆)
      时间损失/车: car 29.80 → 29.53 (−0.27 [−0.91, +0.40], GS 更优 50%, p=0.76); bus 16.47 → 15.75 (−0.72, p=0.25); all 29.32 → 29.05;
      ambulance 16.09 → 19.02 (+2.93 [−4.99, +12.02], n=8)。J(531) 30.53 → 30.22 (−1%, 2/4)。
      → 两法在 1x1 上统计不可分 (与旧表 −3% / 28 胜 40 一致, 旧表的 "GS 胜" 在逐车配对下不显著)。
      优先级核验: 同口同 movement 比 amb/car 0.19 / 0.24, bus/car 0.49 / 0.46 —— 两臂都落实了优先级 (救护车停车只有同路径小汽车的
      1/5), 8STD 对救护车略更强。救护车到达绿灯率 0.12 / 0.00, 无停车通过 0.38 / 0.12, 服务延迟中位 8 / 8 s。
  3.2 1x3 (275 vs 265, 275 ep4550-4700 / 265 ep3900-4050, 每检查点 2353 辆)
      car 40.75 → 41.36 (+0.61 [+0.17, +1.10], p=0.001); bus 13.26 → 16.14 (+2.88 [+2.11, +3.64], p=1e-13); ambulance 30.24 → 46.43
      (+16.19, n=8); all +0.74 (p=3e-6); J +3% (1/4)。相对时间损失 bus +20%, ambulance +61%。
      → 1x3 上 GS 全面显著更差, 公交/救护车差得最多, 与旧表结论一致且更清楚 (旧表 J +8%, 3/40)。
      优先级核验: amb/car 0.13 / 0.18, bus/car 0.36 / 0.53 (两臂都 < 1); 救护车到达绿灯率 0.29 / 0.12, 无停车通过 0.54 / 0.08,
      服务延迟 6 / 9 s —— GS 在 1x3 的问题在优先级类上最明显。
  3.3 Dublin 11:00 (208 vs 211, ep650-800, 每检查点 4637 辆)
      car 28.38 → 24.92 (−3.46 [−3.79, −3.10], 56%, p=1e-90); bus 24.46 → 23.59 (−0.87 [−2.28, +0.49], p=2e-5); ambulance 74.84 → 67.06
      (−7.78 [−27.5, +11.5], n=16, p=0.38); all −3.33 (p=1e-95); J 30.88 → 26.93 (−13%, 4/4); 相对时间损失 car −24%, bus −7%, amb −10%。
      → GS 显著更好, 幅度比旧表 (per-visit −51%) 小得多: timeLoss 含非受控口排队与路段减速, 那部分两臂相同, 所以相对差被稀释;
        逐车 −3.5 s、相对 −24% 是更保守也更可信的表述。
      优先级核验: amb/car 0.31 / 0.34, bus/car 0.62 / 0.56 (都 < 1); 救护车到达绿灯率 0.53 / 0.67, 无停车通过 0.75 / 0.83,
      服务延迟中位 7 / 9 s, 最长单次停 8 / 13 s。锁死 0 / 0。
  3.4 Dublin 02:00 (283 vs 284, 原救护车路线, 每检查点 1650 辆)
      car 13.21 → 12.04 (−1.16 [−1.31, −1.01], 57%, p=1e-50); bus 13.27 → 10.76 (−2.51, p=0.002); ambulance 24.88 → 23.13 (−1.75 [−6.07, +2.76],
      n=8); all −1.18; J −9% (4/4)。相对时间损失 car −9%, bus −18%, amb −7%。
      → 与旧表方向一致 (GS 胜), 且救护车在 1 s 分辨率的 timeLoss 下 GS 略优 (旧 per-visit 5 s 采样给出 +36%): 旧表的救护车 "差"
        主要是量化产物。优先级核验: amb/car 0.46 / 0.69, bus/car 0.67 / 0.45; 救护车到达绿灯率 0.46 / 0.67, 无停车通过 0.81 / 0.88。
  3.5 Dublin 02:00 探针路线 (287 vs 288, 救护车 = 11h amb_1 × 2)
      car 12.83 → 12.33 (−0.50 [−0.65, −0.36], p=3e-15); bus 11.74 → 11.88 (+0.14, p=0.82); ambulance 11.71 → 11.07 (−0.64 [−5.42, +4.07], n=8);
      all −0.50; J −4% (3/4)。救护车到达绿灯率 0.75 / 0.75, 无停车通过 0.88 / 0.88, 服务延迟 1 / 1 s, 最长停 7 / 9 s。
      同口同 movement 比 amb/car 1.62 / 3.02 (> 1): 在 1448436 的左转 movement 上, 救护车比走同一左转的小汽车停得多 —— 层数只有 3,
      每层救护车 1-2 辆, 数值不稳; 但方向提示该口对救护车没有偏向 (与 DUBLIN_02H_PROBE §3.3 的 "反应式" 结论一致)。
  3.6 跨场景小结 (新表口径)
      - 方法差异: 11h / 02h / 02h 探针 GS 显著更好 (car −3.5 / −1.2 / −0.5 s), 1x1 不可分, 1x3 GS 显著更差 (bus +2.9 s)。
      - 优先级落实 (同口同 movement 比 < 1): 1x1、1x3、11h、02h 两臂都成立; 救护车比同路径小汽车少停 55-87%, 公交少停 30-64%。
        这是旧表保序门给不出的、防路线构成的结论。
      - 救护车 n = 8-16 辆次, 所有救护车行的 CI 都跨 0, 论文里只报事件指标 (到达绿灯率 / 无停车通过率 / 服务延迟), 不报方向。
