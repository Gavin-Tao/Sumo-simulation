二、三个发现

  F-1x1a  1x1 的 g 函数几乎不分优先级, 且被 car 主导:
    所有臂 car(l1) 最高 (1.15-1.44), bus/amb 桶一律 α≈0.9-1.0。
    与 Dublin (α 跨级 1→4.11) 天壤之别。机制: 单路口对称几何 + 16维
    slot (无下游压力块), g=自需求分主要读 car 队列 (car占80%);
    优先级由对决函数 S / reward 承载, 不进自需求编码。
    → 论文点: "优先级内化的位置是场景函数" — 多路口压力把优先级
      逼进 g, 单路口不逼。这是 F1(Dublin)的边界条件, 强化而非削弱。

  F-1x1b  数值换约不动 g-α (价值层证据):
    220(5-3-1) vs 228a(4-2-1微调) α 逐位近同 [1.16,.96,.96,.95,1.01]
    ≈ [1.15,.95,.95,.93,.97]。→ 微调没改自需求内化 = 与行为侧
    "228a≈do-nothing"互证; do-nothing 的价值函数确实还"以为"是 5-3-1,
    却被重评分成 4-2-1 最优 (内化契约≠部署契约, 而它是冠军)。

  F-1x1c  重排未使 bus 在 g 中上位 (反直觉但自洽):
    3-5-1 名义要 bus(l5) 居首, 但 bus 桶 α 不升反居低位 (从头 229b
    0.61-0.85 [09复核: draw 敏感], 微调 228d 0.94-0.96)。bus 虽稠密(20%),
    g 函数仍不给它高权 — 再证 1x1 的优先级不在 g。
    [09复核软化] "从头比微调更极端"方向一致 (229b ≤ 228d 两 draw 均成立)
    但差距大小不稳 (0.33 或 0.11), 勿引 "0.61 vs 0.94" 点值对比;
    机制表述降级为: 从头训练未把 bus 需求提升进 g, 微调亦未 — 两者在 g
    通道同样"不动", 重排的真正落点在 S 通道 (见 S-2)。

三、对论文 (B1 章) 的用法
  - 主定理仍是 Dublin α (强分级, R²0.774): 优先级被内化且失真;
  - 1x1 α 作边界条件: 内化位置随拓扑迁移 (单路口→S/reward, 多路口→g);
  - 换约三臂 (F-1x1b/c) = KAN 作换约验证器: 读出确认"数值换约不进
    价值层, 重排也不进 g" — 与行为/性能判决三方互锁。
  - 待补: S(对决)函数的 1x1 α (验证优先级是否在 S); Dublin vintage
    α 轨迹 (ep215/350/800, 数据已提取待拟合) = 训练期预警器主张。

六、三个发现 (回答用户"g平坦为何amb效果好")
  S-1  S 通道也 car 主导, amb 对决优势近零 (0.01-0.03) — 与 g 同构。
       → 1x1 上 amb 的良好控制既不在 g 也不在 s: 是对称几何的副产品
       (amb 极稀疏 NS1%, 节拍器轮转顺带服务 NS, amb 搭便车)。这修正
       了前一节"优先级在S不在g"的猜测: 1x1 上两个通道都不特别编码
       amb, amb 优先近乎"免费搭车"而非"学出来的"。与 Dublin (g-α
       amb=3.3 真内化) 对比 = 场景决定"优先靠学还是靠几何"。
  S-2  但重排 3-5-1 在 S 通道露马脚 (g 通道没有): 228d 微调 bus 对决
       优势 0.03→0.12 (4×)。→ 当契约变更确实被内化时, 它进的是 S
       (冲突裁决) 而非 g (自需求)。KAN 定位了优先级内化的通道 = 对决。
  S-3  微调(228d bus0.12) 比从头(229b bus0.03) 内化重排更彻底 →
       与行为侧 v4微调(75.5)胜金标准(94.9) 互证: 微调赢, 是因为它
       在对决函数里真学到了 bus 优先, 从头训反而没学进去 (car 主导的
       梯度把 bus 折叠掉了)。KAN 给出了"微调为何胜从头"的价值层机制。

九、三个判读
  V-1  Dublin amb 优先完全在 g(自需求), 从不在对决(s-amb 三vintage 恒0)。
       = 软需求加权, 非硬冲突优先 → 解释 amb 服务为何脆: g-α 一漂移,
       amb 服务即崩, 无对决层兜底。(与 1x1 的 S-2"重排进对决"对比:
       Dublin amb 进 g, 1x1 bus重排 进 s — 优先级内化通道随场景/类别变。)
  V-2  ★g-α_amb 在 ep800 崩塌 (2.64→0.20, 13×), 权重转移给 bus
       (3.4→5.05)。= §5a 行为侧"amb 后期丢失"的价值层签名, 方向完全
       吻合。→ KAN 作"灾难性优先级丢失监测器": 成立。
  V-3  [09复核重写] g-α 无法可靠区分 ep215学反 vs ep350学对 — 结论不变,
       但理由更新: 原 draw 两者近同 (2.78 vs 2.64), 新 draw 反而分开
       (2.68 vs 1.60); ep215-ep350 差随 draw 横跳 [0.14, 1.08], 落在抽取
       噪声带内不稳定 → 不是"数值相同故分不清", 是"该差值本身不可复现,
       不能作判据"。细粒度预警不成立的判决维持。
       (V-2 不受影响: 崩塌幅度 ≥8×, 两 draw 都远超噪声带。)
  诚实警告: ep800 g-R²=0.30/0.18 (两 draw, 线性 shared-levels 拟合差,
  可能 ep800 的 g 更非线性) → amb≈0.2 数值在弱拟合模型上; 但方向
  (amb↓bus↑, 且 [09复核] s 通道同向: bus s-adv 0.020→0.037 接管对决)
  与行为证据独立吻合, 崩塌定性可信、精确幅度存疑。终审需多 draw α 置信带
  (≥5 draw, 与 E3 同级的发表前置)。

十一、失真的"搬家" — multihead 不减失真, 只是换了藏身处
  名义权重(BNF)   [car1, l2:2, bus3, l4:4, amb5]  ← argmax时精确相乘, 权重零失真
  有效决策权重     [car1.0, 0.03, bus0.66, 0.05, amb0.45]  ← 严重欠实现!
  头价值尺度       [car1.11, 0.005, bus0.18, 0.003, amb0.044]  ← 稀疏类头近平
  ★仅在场条件读法(控制"少见"混淆后):
    car(l1) n=1592: own-α 1.07, 尺度 1.06  ← 在场时车头强读自己级
    bus(l3) n=800 : own-α 0.05, 尺度 0.16  ← 在场时仍弱读
    amb(l5) n=79  : own-α 0.04, 尺度 0.09, R²0.40  ← 在场时几乎不读自己级

  结论(1x1):
  D-1 multihead 的设计主张(权重精确)结构成立: BNF 的 5 在 argmax 精确相乘,
      不学=不失真。但失真没消失, 搬到了"头价值尺度": amb/bus 头近平。
  D-2 ★仅在场读法是决定性证据: 即使 amb 真在进口道(n=79), amb 头 own-α
      仍仅 0.04 (car 1.07 的 1/27) — 这不是"amb 少见被稀释", 是 amb 头
      genuinely 欠训练。稀疏梯度的病根在 multihead 里换了表现形式(权重→
      价值尺度)但没被治好: 独立头隔离了"方向性挤压", 但治不了"信号量太少"。
  D-3 净效应: 名义 amb 5× → 有效决策影响 0.45×, 比单头更隐蔽(精确权重给
      假信心, 头却是平的)。→ 修复方向不是"更多梯度隔离", 是"给稀疏类更多
      梯度信号"(PER/分层重放/尾部加权目标), 与 F3/G2/A2 一线同源。
  D-4 边界: 1x1 amb 极稀疏(NS 1%, 79/2400步)。multihead 的隔离优势是关于
      "方向"的, 这里问题是"量级"——公平检验需 Dublin(amb 更密)的 exp218,
      从未跑。1x1 上的结论: multihead 不比 B+enum-frap 好(失真未减 + 性能
      219<220)。Dublin 待验。
