╔══════════════════════════════════════════════════════════════════════════════╗
║  Part 0: TL;DR —— 一条已被数据闭环的机制链                                     ║
╚══════════════════════════════════════════════════════════════════════════════╝

  现象: loss 先降(正常) → q_abs_max 突然抬升 → loss 转升且不再回头。
  机制链(七环, 每环有数据, Part 4):

   [种子] reward≤0 ⇒ 真 Q 必然≤0, 但训练早期 q_mean 已是【正的】
          (+4→+31, ep10-20) —— max 算子的系统性高估偏置;
   [扳机] ε 按 update 数衰减, 到底时刻 = 坍塌起点, 4/4 run 对齐:
          192/198 (decay5000): ε≈0.06@ep20 → qmax 跳变 ep21-26;
          203/204 (decay30000): ε≈0.05@ep130-160 → 坍塌 ep120-150;
   [悬崖] Dublin 接近饱和: 错配的策略数百秒内排队→短车道溢出→区域
          锁死, 不可自愈 (ep50 模型 rollout: 停驶数单调爬到 393/481);
   [量爆] 锁死后 reward 从 −0.34/步 → −50/步/路口 (无界), 回报量级
          瞬间放大 2 个数量级 → TD 目标剧烈非平稳;
   [冲刷] buffer 仅 3.86 episode (192/198): 4 个 episode 后 buffer 全
          是锁死数据, 共享 MLP 灾难性遗忘"正常交通"的 Q;
   [棘轮] 大 TD 误差 × max 选高估 × 目标网 20 updates 就同步(无锚)
          → |Q| 单向棘轮: q_mean 符号每 ~6 ep 鞭打一次(≈1.5×buffer
          周转), 中枢一路向正漂: ep800 q_mean=+2.0e5 (真值 −1583,
          5 个数量级、方向反);
   [假回] loss = (Q−target)², 两者都被棘轮抬高 → loss 随 |Q|² 长
          (1.8e3@ep100 → 3.3e7@ep800) —— "loss 越来越差"不是欠拟
          合, 是 Q 函数本身在膨胀。
  ★ 最重要的新证据: exp203/204 (Double+慢目标+Huber+大buffer+长探索
    +obs 三修) 只把健康期从 ep24 推迟到 ~ep130, 同样的棘轮照样发生
    (q_mean +0.5@ep40 → +74@ep150 → +2683@ep400, eval −17 → −329 →
    −1379) —— 现行工具箱是【减速器】不是【治愈】, 缺一个把 Q 钉在
    物理可行域的锚 (Part 7 R1)。


╔══════════════════════════════════════════════════════════════════════════════╗
║  Part 1: 训练机制事实 (代码核对, 误读会毁掉后面所有推断)                       ║
╚══════════════════════════════════════════════════════════════════════════════╝

  - 【一个共享 DQN】服务 18 个路口 (train.py:315): 单网络、单 buffer。
    每决策步 18 条 transition 入 buffer、做【1 次】update (非每路口
    一次); 每 episode 720 决策步 → 720 updates、12960 transitions。
  - buffer 周转: 192/198 capacity 5e4 → 3.86 ep; 203/204 3e5 → 23 ep。
  - ε = eps_end + (0.9−0.01)·exp(−count/eps_decay), count=update 数:
      decay 5000 → ε: ep10≈0.22, ep20≈0.061, ep30≈0.022 (到底);
      decay 30000 → ε≈0.056@ep120, 0.027@ep150 (到底)。
  - 目标网同步: 192/198 每 20 updates (每 episode 同步 36 次 — 目标
    几乎贴着在线网走, 无锚定作用); 203/204 每 720 (每 ep 1 次)。
  - wandb 口径: train/loss = 当 episode 全部 update 的均值;
    train/q_abs_max = 当 episode 内各 batch |Q| 最大值的最大值;
    train/q_mean = batch Q 均值的 episode 均值。
  - reward = −Σ_p p·avg_wait_p /100, 每路口, 恒 ≤0, 【无下界】。
  - max_green=50 强制轮换: 相位熵永远≥~0.5 — 它是安全兜底, 也让
    "相位锁死"类指标【看不出】策略坍塌 (Part 2.4)。

╔══════════════════════════════════════════════════════════════════════════════╗
║  Part 2: 训练曲线取证                                                          ║
╚══════════════════════════════════════════════════════════════════════════════╝

  2.1 Q 符号判别 —— 高估自激的铁证
  ────────────────────────────────
  reward 恒≤0 ⇒ 任何策略的真 Q ≤0。实测 (exp192, 按 episode):
     ep10: loss=0.158  q_mean=  +4.0   qmax=21     ε=0.223
     ep20: loss=1.43   q_mean= +31.0   qmax=53     ε=0.061   ← best ckpt
     ep30: loss=1.2e3  q_mean=−178.8   qmax=5714   ε=0.022   ← 锁死数据涌入
     ep40: loss=519    q_mean= −34.0   qmax=5422
     ep100:loss=1.8e3  q_mean= +334.9  qmax=1.5e4
     ep200:loss=728    q_mean= +2194   qmax=4143
     ep400:loss=8.0e4  q_mean=+1.32e4  qmax=2.8e4
     ep800:loss=3.3e7  q_mean=+2.01e5  qmax=6.6e5
  exp198 同构 (ep20 q_mean=+8.3 → ep30 −85.5 → ep800 +1.98e5)。
  解读: 早期 q_mean>0 = 高估已在(种子); ep30 的负摆 = 第一波锁死回报
  的诚实拟合; 之后正向棘轮直到 +2e5 —— 真值不可能为正, 这是纯偏置。

  2.2 跳变定位与 ε 对齐
  ─────────────────────
  qmax 突变(>3×前一 ep): exp192 在 ep24 (61.9→690);
  exp198 在 ep21 (19.9→65) 和 ep26 (64→493)。
  两个 run 的 best ckpt 都停在 ep20 —— 即 ε 到底(0.06@ep20)的那一刻。
  跳变 = 探索停止后, 策略开始全力利用被高估的 Q → 第一批锁死 episode
  的回报(−1e3~−3.6e4/路口/ep)进入 buffer → batch 里出现巨大 TD 目标。

  2.3 "周期性"的来源
  ──────────────────
  ep30-250 区间 q_mean 符号翻转 5 次, 翻转间隔中位 6 ep ≈ 1.5× buffer
  周转 (3.86 ep): 锁死波数据冲入 → Q 被拽负; 锁死数据被新 episode 数
  据顶出 → max 偏置又把 Q 抬正; 如此往复, 且每个来回中枢上移 (棘轮)。
  你在 wandb 上看到的"q_abs_max 周期性突然变差"= 这些波 + ep24 一次
  性跳变 + 后期的阶梯抬升。

  2.4 相位熵: 没有单相位锁死 —— "坏"不在这
  ─────────────────────────────────────────
  18 路口 ep800 相位熵最低 0.48 (389281), 多数 >0.65 —— max_green=50
  强制轮换兜住了熵。坍塌的形态不是"卡死一个相位", 而是【时序错乱 +
  分配错误】(Part 3 的动作/车道证据)。⇒ 以后用相位占比判健康会漏诊。

  2.5 ★ 跨 4 run 的 ε-floor/坍塌对齐表 (本文最强的因果证据)
  ─────────────────────────────────────────────────────────
     run     eps_decay  ε到底时刻     坍塌起点(数据)
     exp192    5000     ~ep20-30     qmax 跳变 ep24; best 停在 ep20
     exp198    5000     ~ep20-30     qmax 跳变 ep21/26; 同上
     exp203   30000     ~ep130-160   eval 从 −26(ep120) 永久劣化到
                                      −329(ep150); q_mean +4.5→+74 同窗
     exp204   30000     ~ep130-160   同 203 (q_mean ep433=+2.1e4)
  两种完全不同的衰减时间表, 坍塌起点跟着 ε-floor 平移 —— 探索的消失
  是扳机, 不是巧合。

  P10[C] max_green 强制轮换与 Q 学习的交互 (强制动作产生的

╔══════════════════════════════════════════════════════════════════════════════╗
║  Part 7: 干预选项 (全部待批准, 我不会自行改码/启动)                            ║
╚══════════════════════════════════════════════════════════════════════════════╝

  R1 ★ TD 目标钳位 (领域不变量锚):
       target = min(r + γ·maxQ', 0)   (或等价钳 maxQ'≤0)
     reward≤0 ⇒ 真 Q≤0 是数学事实, 钳位零风险、一行代码, 直接斩断
     正向棘轮 (E1/E6 两环同时失效)。负向深渊由 E4 的修复 (R2) 兜。
  R2 reward 有界化: r ← max(r, −c) 或 r/(1+|r|/c), c≈10
     (Atari clipping 的本地版; 代价: 极端坏态间的区分度饱和 — 对
     "别进入锁死"这个学习目标无伤)
     【2026-06-12 用户否决, 退役为应急预案 — 理由与触发器见 Part 9.2】
  R3 γ: 0.99→0.95 (自举链 100→20 步, 偏置放大率 ÷5; 5s/步×20=100s
     视界对信号灯足够)
  R4 ε 永久下限 0.05 (+可选: 检测到 eval 崩盘时 ε 重注 0.3) —
     直接对抗 E2; 803 的健康期证明带探索时系统能稳定运行百余 ep
  R5 per-junction reward 运行归一 (z-score 或除以 running |r| 均值)
  R6 网络侧: LayerNorm / weight-decay / 更小 lr-late (常规药)
  推荐最小组合 exp205 = exp203 + R1 + R4 (一行钳位 + 一个数);
