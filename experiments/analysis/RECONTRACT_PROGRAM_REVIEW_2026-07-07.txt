§0a 终版判决 (2026-07-08 凌晨, E1 金标准 + E2-lite 完赛后 — 覆盖 §0 的
    临时表述; 单 seed, E3 多 seed 复核仍为发表前置)

  ★ 4-2-1 坐标系 (E1a=exp229a, from-scratch 2000ep):
      do-nothing (220 重评分)      J 39.7 / mr -30.2   ← 全场冠军
      金标准 best vintage          mr -32.5 (输 do-nothing)
      金标准 收敛末10              J 67.3±10.5 / mr -40.4
      微调家族 (227/228)           J 65.0-73.0
    → 65-73 不是"微调失败盆地", 是 4-2-1 reward 的 TD 吸引子本身 —
      从头训 2000ep 也收敛到那里。220 的 5-3-1 母策略重评分严格
      优于原生 4-2-1 训练的一切产物。用户问题"接近金标准"的答案:
      已在金标准之上, 无需任何动作。
    机制回归: 4-2-1 的 bus-car 边际=1 (5-3-1 为 2) → 金标准 bus
      11.0 vs do-nothing ~7.6 — 老倒挂扫描的 margin 理论在纯效率
      维复现: 弱边际 reward 的 TD 解质量差, 强边际契约是同排序
      目标的更好课程。
  ★ 3-5-1 坐标系 (E1b=exp229b):
      v4 微调 (300ep)              J 75.5 / mr -42.9   ← 胜金标准收敛
      金标准 best vintage          mr -41.3 (边际优于微调 best)
      金标准 收敛末10              J 94.9±13.6 / mr -48.4
    → 桶交换+physics-frozen 300ep ≈/超 从头训 2000ep; 15% 成本
      拿到 ≥100% 质量。warm-start 继承 5-3-1 母策略的训练红利。
  ★ E2-lite (exp229c, warmup20k): 热身期纹丝不动 (-30.2), 学习一
    开始即劣化入同一吸引子 (末10 J 71.8) → M2-大小变体证伪;
    M2-窄分布变体未测; 当前最优机制假说 = M3 "TD 定点绕路+吸引子
    质量" (起点非新约 TD 不动点, 且新约不动点本身更差)。
  ★ 统一叙事: "5-3-1 强边际母策略 + 零训练重评分 (数值) / v4 轻
    微调 (重排)" 全面统治邻近契约空间; 残差头(②)/multihead(①)
    对 4-2-1 类不再必要 (除非 E3 多 seed 翻案), multihead 的价值
    回归其原生卖点 (连续旋钮+部署即调)。

§0 站得住的判决 (E1 前的临时表述, 已被 §0a 精化)

  V1 同序数值换约 (4-2-1): 不训练 = 最优。do-nothing 锚 J=39.7,
     全部五种微调变体落在 65.0-73.0 盆地 (227a 全参 67.5 / 228a v4
     冻结 65.0 / 228b rscale 68.3 / 228c 叠加 65.9 / 228e v3 头 73.0)。
  V2 M1 尺度冲击假说被证伪: rscale 9/7 对 J 无改善 (68.3 vs 67.5)。
  V3 重排换约 (3-5-1): v4 physics-frozen 微调 = 微调家族最优
     (J 75.5 < 全参 100.9 < 零训练交换 ≈105 << v3 头 only 564 灾难)。
  V4 v3 heads-only 双侧判负: 4-2-1 侧漂入倒挂 (amb 7.5 > bus 6.1),
     3-5-1 侧灾难 (冻死 enc 背 OOD 嵌入)。

§1 结论可信度审计 (哪里还不牢)

  P1 金标准臂缺失 (最大缺口): 所有比较都在 {do-nothing, 微调家族}
     内部。没有 from-scratch 4-2-1 / 3-5-1 训练臂, 于是回答不了:
     (a) do-nothing 的 39.7 离真 4-2-1 最优有多远 (可能 do-nothing
     已近优, 也可能真最优 ~30 而我们全家都差);
     (b) 3-5-1 的 75.5 在绝对坐标上是好是坏。
     → V1 的准确表述是 "微调不如不调", 不是 "39.7 已最优"。
  P2 单 seed 单场景: 全部 1x1、每臂单 training seed、eval_seed=123。
     do-nothing 优势与 v4 优势均未经多 seed 复核; L1 密度定律警告
     amb 相关结论在 Dublin 可能翻转。
  P3 J 是代理量: J=契约加权 per-visit 停车时长, 不含频率/速度维。
     228d 重算 (本文 §2-P15) 显示分维度结论会分化 — 判优必须回到
     §6.6 的门+价结构, 单一 J 只做家族内快筛。
  P4 300ep 预算框架: 227c/228d 的 best 都在 270-300 (未饱和)。
     "v4 优于全参"严谨说法 = "在 300ep 预算内优于"; 渐近孰优未判。
     对"廉价适配"故事这正是对的框架, 但须写明。
  P5 起点锚定验收仍未机器化: 228 的 best 选点仍是纯滑窗 reward;
     若已实现 F1+锚定, 4-2-1 侧四臂会自动发布起点。协议在文档里,
     代码里还没有。
  P15 228d 合规的分维度真相 (本次重算, 末20窗口统计, 修正"40%
     逐评严格率"的量子化误读):
       停车时长维: bus 4.81 < amb 5.00 < car 33.1 (中位/均值双过 ✓)
       停车频率维: bus 0.60 ≥ amb 0.50 (中位) — 未翻序 ✗, 差距
         恰在 amb 的 0.5 量子上
     → 3-5-1 重排在 300ep 交付了强度维、未交付频率维。频率维的
       残余 amb 优势是 5-3-1 母策略的遗产。V3 的准确表述: v4 是
       微调家族最优, 但完全合规尚未达成。

§2 未解剖的机制

  M2 (fresh replay 分布塌缩) 从未被单独测试: 227/228 全部从空 buffer
     起步。两个未跑的关键对照:
     (a) 热切换臂: 同一训练进程内 ep N 处换 reward 表, replay/优化器
         原地保留 — 这才是部署语义下最自然的"继续训练", 也是 M2 的
         直接解剖刀;
     (b) 高探索微调臂: eps_start 0.2 重新多样化 replay。
     若 (a) 显著优于 227a, 则 65-73 盆地的主犯是空 buffer 而非微调
     本身 — 会部分推翻 V1 的"微调无益"表述。
  228e 漂入倒挂的机制未证: 猜想 = amb 权重 5→4 + 近贪心 replay 下,
     头层重定标先牺牲 TD 质量最小的稀有类 (L1 的微调版), 但无探针
     证据。可用 227 系 ckpt 逐代致盲 gap 曲线验证。
  v3 的 lr 混杂未排除: heads-only 34 参数用 lr 1e-4 可能过小
     (设计稿说过可回 1e-3 但配置沿用 1e-4 求可比性)。228f 的
     主动劣化 (564) lr 救不了, 但 228e 的 73.0 有 lr 混杂余地 —
     不影响 V4 大方向, 影响 v3 的精确定位。
  220 的 replay/优化器状态没有保存: checkpoint 只有权重, 使
     "真·继续训练"无法回溯构造 — 工程缺口, 见 §4-I4。

§3 覆盖缺口

  G1 契约谱系: 只测了近邻数值 (4-2-1) 与相邻重排 (3-5-1)。缺:
     极端数值 (10-3-1)、全倒置 (1-3-5)、新类型入桶 (truck→l2,
     MULTIHEAD §6 的 new-type 矩阵)、连续漂移 (5-3-1→4-2-1→3-5-1
     串行适配的损伤累积)。
  G2 Dublin 未验证: 全部结论悬在 1x1。
  G3 契约 MPC 对照缺席 (决定性): FIFO 规划器无头尺度偏置、无 OOD
     问题、天然支持任意表。若 MPC 探针在 3-5-1 上 < 75.5, 整个
     微调线降级为 fallback; 若 >, 微调线价值确立。这是当前最便宜
     且最高信息量的一步 (探针级, 零训练, 设计已在 RESEARCH_
     DIRECTIONS §2.8c)。
