§1 动机 (证据链)

  标量 5-3-1 训练把 BNF 权重"烤"进共享梯度, 稀疏类别被稠密类别稀释:
  KAN α 读出 (exp211): 名义 l3=3/l5=5, 有效 l3=4.11/l5=3.29 —
  bus 过度内化, amb 欠内化; 行为侧三条独立证据同向 (exp211 后期 amb
  回吐、amb xts 劣于 208、MoE gate 的 amb 交易)。
  结论: "让网络自己学会 5 倍"这条路结构性走样。修法 = 训练时解耦
  (每级一个头, 只吃本级 reward 通道), 决策时把 BNF 权重显式相乘:
      a* = argmax_a Σ_l w_l·Q_l(s,a),  w = BNF 表本身
  "5 倍"由公式保证, 不再是学习目标 — 比例语义构造性成立。

§2 数学要点

  a) 通道分解 (恒等式, 单测锁死):
     原 reward = -(Σ_l l·avg_wait_l)/100;  vec[l-1] = -avg_wait_l/100
     ⇒ scalar ≡ Σ_l l·vec[l-1]。默认决策权重 = bucket 值 [1..5] 时,
     复合 Σ w_l Q_l 估计的正是标量 B 线的同一目标 — 锚定性质:
     exp218 与 exp208 优化同一目标, 仅估计方式解耦。
  b) 联合策略一致 target (正确性纪律, 与 presence-mask D1 同类):
     y_l = r_l + γ·Q_l^target(s', a*),  a* = 加权分数在 s' 上的
     masked argmax (double: online 网选 a*, target 网逐头取值) —
     所有头 evaluate 同一个 a*, 各头各取 max 会学到不同策略的价值,
     决策时求和无意义。
  c) 固定 5 头 (PRIORITY_LEVELS 零样本不变量): 缺席等级 reward 恒 0,
     头学成常数, 不影响加权 argmax — 任意 BNF 表零改动。
  d) 换表零重训的诚实边界: 决策立即精确执行新权重, 但头价值是旧
     联合策略下学的 — 小幅换表≈零样本可用, 大幅换表需短暂微调
     (用户已接受微调路线; GPI 多策略维持否决)。

  二次审查补记 (2026-07-03 深夜, 30 项检查单无正确性 bug; 两个诚实边界):
  * 解耦是输出层级的, trunk 仍共享: fc1 由五头共同驱动。但损失对
    (B,5) 取均值 ⇒ 每头的 TD 误差在梯度里等权 — 标量版里 amb 项
    按 w·avg 的相对幅度贡献 (多数步接近 0), 多头版 amb 头误差与
    car 头同响。稀释在机制上被压缩而非彻底消除; P2 的逐头 KAN
    校准检验正是为量化残余而设。
  * 损失尺度: huber 对 (B,5) 取均值 ⇒ 单样本梯度尺度约为标量版
    1/5 (lr 未动, 与 exp208 同值)。这是估计器差异的一部分, 不构成
    目标不公平 (锚定性质在目标层); 若 exp218 学得偏慢, 首查此项
    (等效补偿: lr 或 loss reduction 口径, 都是显式可报告的选择)。
  * 逐项确认安全的关键点存档: sample() 解包顺序与 update dict 键
    一一对应; 缺席等级通道恒 0 (非 NaN); 空路口 vec 全零与原标量
    -0.0 一致; cache 无跨集陈旧 (store 前必有当步 env.step 刷新);
    eval 污染 cache 无害 (eval 不入 buffer); moe/enum/transformer
    与 multihead 由 agent_arch 单键天然互斥; weights 默认 =
    bucket 值 [1..5] 而非 per-type 表值 — 与"bucket 即权重"的
    对齐规则一致, 分解恒等式因此闭合。
