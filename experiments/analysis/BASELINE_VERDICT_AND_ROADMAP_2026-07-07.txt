§4 横切机制 (四条定律化表述)

  L1 信号密度决定"学得且守住":
     amb 反应质量 ~ amb 在场决策步的密度。1x1 (2 amb/eval 集中过单
     路口, NS 专属需求) → 三种架构全部学得且 2000ep 无一丢失;
     Dublin (1.1 amb/eval 摊 18 路口) → MLP(207) 学得弱但守住,
     FRAP(211) 学反→学对→丢失。含义: 修复目标不是"让它看见"
     (都看得见), 是"让稀有信号的梯度质量不被主流类覆写"。
  L2 enum-FRAP 的价值是场景函数:
     不规则多路口 (Dublin): 组合相位+路口无关 obs → 系统面大赢;
     规则单路口 (1x1): 4 相位已近优, 12 相位只付探索/拟合税 →
     效率 -27%, 但 movement-duel 结构仍给出最强 amb 分离。
     → "enum 是否 work"不可脱离拓扑回答; 论文叙述按此分岔。
  L3 复杂价值头的稳定性税:
     朴素 MLP(217) 最稳; FRAP(220) 稳但效率上限低; multihead(219)
     巅峰持平但震荡+终段崩盘 (5 头联合 argmax 的目标漂移面更大,
     且 1x1 批次未开 double/huber/grad_clip — Dublin 稳定化包未随
     架构迁移)。219 崩盘归因未定谳: 缺第二 seed。
  L4 选点即政策:
     滑窗 reward 判据两次救场 (219 崩盘前退休、211 避开失稳),
     一次踩坑 (211 best 落在 amb 学反 vintage)。选点标准本身
     是优先级语义的一部分 → §5-F1 复合判据。

§6 优先级评价: 病例与六层 SLA 协议 (新方向, 用户提出)

  6.1 病根: 排序合规是偏序, 不是全序。
    病例 1 (用户假设数字, car/bus/amb 归一等待):
      A=(0.5, 0.3, 0.1) vs B=(0.6, 0.2, 0.15), 两者排序均正确。
      5-3-1 加权: A=0.5+0.9+0.5=1.90 < B=0.6+0.6+0.75=1.95 → A 优;
      5-4-1 加权: A=0.5+1.2+0.5=2.20 > B=0.6+0.8+0.75=2.15 → B 优。
      → "哪个更好"在数学上不适定, 除非显式声明类间汇率 (权重表)。
        同一对方案, 汇率表一换, 结论翻转。
    病例 2 (真实, §2.1): 217 vs 220 末窗 —
      5-3-1 加权成本: 217 = 30.12+3×5.45+5×4.75 = 70.2
                      220 = 31.96+3×7.70+5×4.68 = 78.5 → 217 优;
      分离/尾部: amb<bus 217 p=0.045 (边缘) vs 220 p=4.6e-11;
      amb 强度 220 4.68 略优 → 优先级视角 220 优。单标量必然抹掉
      这对矛盾。
    病例 3 (真实): 220 amb bad-rate 1.00 (每 eval 必停一次) 但强度
      最低 4.68; 217 bad-rate 0.82 但强度方差 2.85 — 频率与强度背离,
      "amb 停不停"与"停多久"是两个指标。
    病例 4 (真实, MoE 文档 §9): bus 整程等待 > car 但每路口 bus < car
      — 路线构成 (bus 穿 3.7 个路口 vs car 2.2) 混杂, 整程/每路口
      口径给出相反排序结论。
    病例 5 (真实, §8/§5a 前科): amb n=1-2/eval → 指标 0.5 格点量子化
      + 固定 eval seed 的到场对齐彩票 — 单点比较无意义。

  6.2 提案: Priority-SLA 六层评价协议 (每层都有 house 数据先例)
    L0 完整性门: completion/pending/teleport 逐位对账 — 不过门不进
       比较 (先例: §9 完整性体检)。
    L1 契约声明: BNF 权重表 = 类间汇率, 显式随结果发布; 加权成本
       是唯一合法"主标量", 但只在同契约内可比 (病例 1 的解法:
       不是找"客观"标量, 是把主观汇率显式化)。
    L2 排序合规: 邻对 (p,p-1) 反转率 + 窗口化配对检验 (Wilcoxon)
       + 效应量 (Cliff's δ) — 先例: 211 §4b 16 窗口审计。
    L3 分离度: 尺度不变比值 r_pq = wait_p/wait_q (p>q 期望 r<1),
       报告比值谱而非差值 (跨 demand 强度可比); "分离达标"判据
       r ≤ 1/权重比 可作为强 SLA (5-3-1 下 amb/car ≤ 1/5)。
       [病例 2 数据: 217 amb/car=0.158, bus/car=0.181;
        220 amb/car=0.146, bus/car=0.241 — L3 下 217 bus 分离更好,
        220 amb 分离更好, 矛盾被显式定位到"哪一对"。]
    L4 尾部保障: 稀有类用窗口坏率 (P(停车≥阈值)) 与 CVaR_α, 禁均值
       — 先例: G1 判据。量子化感知: 阈值取格点间 (如 stops/v>0.25)。
    L5 效率价格: price-of-priority = 同架构 flat-权重臂的系统成本差
       — 隔离"优先级本身花了多少", 与"架构好坏"解耦。需要 1-1-1
       对照臂 (当前全批次缺失, 见 §7 exp223)。
    L6 频宽 (frontier): 权重扫描下的 (car, amb) 帕累托曲线; 方法间
       比较用 frontier 支配/超体积, 而非单运营点。传统方法一点一训,
       multihead 一训 N 点 → L6 从奢侈品变标配 (6.3)。
    发布物 = 六层 profile 卡片 + 契约; 拒绝无契约的单数字排名。
    与 5% 显著性同理, L2-L4 全部窗口化+多 seed (S3a) 后才可终审。

  6.4 与文献的差异声明 (投稿定位用): 现有 TSC 文献的公交/应急优先
    评价基本是"报个均值+说一句 ordering 对了"; 多目标 RL 文献有
    frontier 但无优先级契约语义; 本协议的贡献 = 契约显式化 (L1)

    multihead 的组合)。写作时按此三点站位, 病例 1-5 做 motivation。

  6.5 换约保真度评估 (用户问: 训练 5-3-1, 部署改 4-2-1 / 3-5-1 还
      保性能吗; 2026-07-07 探针, exp219 best.pth, 单 seed 单集,
      probe_219_sweep{,_gated}_recontract.py; l2/l4 保持训练值以隔离
      换约效应; 基准点 = 5-3-1: car 29.2 / bus 4.75 / amb 5.0):

    换约          car_s/v   bus_s/v   amb_s/v   判读
    4-2-1 裸      27.6      4.4       10.0      方向全对: amb 降权→让出
    4-2-1 门控    27.3      7.0       10.0        2× 等待, car/bus 受益
    3-5-1 裸      30.3      4.5        5.0      重排完全未兑现: bus/amb
    3-5-1 门控    30.9      5.0        5.0        几乎不动

    结论分三档:
    a) 邻域缩放 (4-2-1): 定性成立 — 响应方向全部正确, 系统总价不劣
       (5-3-1 口径 ep_return -29.4 vs 基准 -30.6, 在混沌噪声带内)。
       但注意后果: amb 绝对等待 (10.0) 已高于 bus (4.4) — 若 4-2-1
       契约仍要求结果层排序 amb≤bus, 此运营点过不了 L2 门。降权
       是真实的取舍, 不是免费的。定量保真度 (与"真在 4-2-1 上训练
       的策略"的差距) 无对照臂, 待 exp223/225。
    b) 优先级重排 (3-5-1, bus 反超 amb): 零重训不成立 — bus/amb
       结果几乎纹丝不动。机制: 各头的 Q 值尺度是在训练权重下校准
       的 (amb 头在 w=5 下学出的价值幅度), 部署时换权重改的是
       合成系数, 改不了头内部的尺度偏置; 温和的重排系数不足以
       翻转决策边界。→ 重排需求要么走权重条件化训练 (exp225,
       UVFA), 要么至少做头输出归一化后再合成 (待验证)。
    c) presence 门控在温和换约下无增益甚至略负 (bus 7.0 vs 4.4):
       它修的是"不在场头的外推噪声"(远距升权时致命), 不修"头尺度
       偏置"。部署建议: 门控作为极端权重的 guard 条件性启用
       (|w-w_train| 大时), 不要常开。
    ⇒ 换挡能力的诚实边界: 同序缩放≈可用 (带 L2 复检), 跨序重排
      = 当前不支持。P-A 论文里这是"负结果做卖点"的素材 (裸组合
      换挡的失效模式 + 条件化训练的必要性论证)。

  6.6 统一判据: 同一契约下"都合规, 谁更好" (用户问题 2 的正面回答)

    推荐标准 = 先门后价 (constraint-then-optimize), 全部窗口化:
    ① 门 (合规性, 不排名): L0 完整性 + L2 排序 (邻对反转率, 配对
       检验) + L4 尾部 (高优类 bad-rate ≤ 阈)。不过门直接出局。
    ② 价 (排名, 唯一标量): J(W) = Σ_c w_c · wait_c, W = 声明的契约。
       权重表本身就是类间汇率承诺 ("1s amb = 5s car"), 承诺之后
       J 是与契约一致的唯一总价。用户例: A=(0.5,0.3,0.1) J=1.90 <
       B=(0.6,0.2,0.15) J=1.95 → 5-3-1 契约下 A 更好, 无歧义。
       "感觉没有统一标准"的根源 = 没把权重表当汇率承诺; 承诺后
       标准唯一, 换表后结论翻转 (5-4-1 下 B 优) 不是缺陷而是换了
       契约 — 这正是 L1 层存在的意义。
    ③ 次级键 (J 置信区间重叠时): 高优类尾部更低者胜 (保护优先
       原则) — 真实例: 217 vs 220 的 J = 70.2 vs 78.5, 217 胜;
       但若契约附带 "amb bad-rate ≤ 0.9" 的硬门, 220 (1.00) 出局,
       根本轮不到比 J — 门与价的分工示范。
    ④ 分离比值谱 r_pq 只做诊断 (解释 J 差从哪一对类来), 不做排名
       项。反例警示: 若把"分离越大越好"计入排名, 会奖励"饿死低优
       类刷比值"的作弊 (car 无谓惩罚使 amb/car 比值变好看, J 会
       揭穿, 比值不会)。这也回答了为什么不推荐 PCI 型 min-elasticity
       指标做主排名: 病例 1 的 A/B 在 J 与 PCI 下结论相反, 而 PCI
       奖励的恰是"均匀过度分离"而非"总福利"。
    ⑤ 稀有类测量纪律 (L4 附则): amb 级结论一律窗口坏率 + 多 seed
       (S3a), 单 eval 数字永不入判 (格点量子化 + 对齐彩票)。
