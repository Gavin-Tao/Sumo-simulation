  ── 1.1 C1 分水岭 (eval seed 污染) ──────────────────────────────────────────
    机制: env.reset(seed) 永久覆写 sumo_seed → 首次 eval (ep5) 后所有训练集
    都在 eval_seed=123 上跑 → 训练集==测试集。修复 (06-09/10): 6 个 trainer
    全部显式传 training_seed ✓ (train.py:179/216/278 已核)。
    判定规则:
      修复前 run (≈exp1-171):
        × 绝对数字 (amb=3.25 等) = "对 seed-123 单一交通模式的记忆"
        ✓ 方法间相对比较 (同协议同污染, 内部公平) — 倒挂存在性、
          协同 vs 无协同的方向性结论仍立
        × 泛化性主张一律不能引用
      修复后 run (exp172+): 第一批 clean; 论文主表应全部来自这里。
    残留风险: env.py:283 的根因未改 (修的是 trainer 调用侧) — 任何 NEW
    trainer 不遵循 training_seed 模式会复发。建议 P1 把根因在 env 层修掉
    (reset 不再永久覆写), 见 Part 5。

  ── 1.2 M1 偏差 (amb=0.0 丢弃) ──────────────────────────────────────────────
    旧绘图把 amb=0 当"无救护车"丢弃, 但 seed 固定下 0 = 完美通过 —
    实测 exp145 末 40 评估有 15 个完美 run 被丢 (越好的方法被丢越多)。
    已修: metrics NaN 哨兵 + 3 个绘图脚本改 NaN 过滤 ✓。
    判定: 修复前生成的旧图里, 5-2-1→5-4-1 的退化被低估; 重画才可入论文。

  ── 1.3 单 seed 现状 ────────────────────────────────────────────────────────
    全部既有结论单 seed; RETROSPECTIVE 已测 541 方法间 amb 差异多数不显著。
    规则不变: winner 必须 ≥3 seed + Mann-Whitney 背书后才进论文。

  ── 1.4 可信数据资产清单 ────────────────────────────────────────────────────
    ✓ 机理诊断类 (不依赖泛化): amb 梯度占比 0.5%、|TD| 0.635、Q-margin/std
      链条、β→0、GAT entropy=ln2、buffer 组成 — 这些是"在该协议下的内部
      测量", C1 不动摇其意义。
    ✓ 因果链 (margin×noise) 与倒挂存在性: 三重独立确认, 定性可信。
    ⚠ 一切 per-visit/avg 绝对秒数: seed-123 口径。
    ✓ exp172-182 (跑完后): clean 基线, 论文主数据源。

  ── 3.1 环境层 latent (env.py / traffic_signal.py) — 换场景才咬人 ────────────
    E1 [MED-latent] begin_time≠0 时 agent 永不 time_to_act (next_action_time
       初始化与 sim_step 起点不匹配, ts.py:86/223)。现配置 begin=0 不触发;
       用真实时段数据 (Dublin 早高峰切片) 时必踩。
    E2 [MED-latent] 多 agent 若 time_to_act 不同步, observations dict 含
       None → .copy() 崩 (env.py:212/401-403)。当前全部 ts 同 delta_time
       → 每步全员同步, 不触发; 异构 delta_time / PettingZoo observe()
       路径是触发面。
    E3 [MED-latent] yellow_dict 假设 N×(N-1) 全对称转移; 相位不对称的
       net (真实路口常见) 在 set_next_phase 直接 KeyError (ts.py:187-198/
       254)。Dublin 网导入后第一个要冒烟的就是它。
    E4 [NOTE] get_lanes_density 容量分母用 getLastStepLength (空车道返 0 →
       分母=MIN_GAP): 数值上无害 (空车道 count=0, density 恒 0), 但口径随
       "当前车型组成"漂移。对照: 新 A/B/T 用固定 veh_len=5 — 口径稳定,
       这是新设计优于旧类的一个小点, 论文可提。
    E5 [NOTE] fixed_ts 模式 num_green_phases=len(phases)//2 假设绿黄严格
       交替; 含全红相位的 net 会算错 (syc 净有全红! 但 fixed_ts=False
       不走此路径)。开 fixed_ts 基线对照前先验证。
    E6 [NOTE] last_executed_action 语义 = "当前/将要的 green_phase" 而非
       传入动作 (被 min_green 拒绝时恰好等于旧相位, "碰巧正确")。
       replay 存储用它 → 语义按"实际执行相位"理解, 文档化即可。

    W3 [NOTE] ambmax 的 amb 项用 MAX、car/bus 用均值 — 这是 exp167-171 的
