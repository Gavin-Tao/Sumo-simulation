╔══════════════════════════════════════════════════════════════════════════════╗
║  1. 实验对象                                                                   ║
╚══════════════════════════════════════════════════════════════════════════════╝
  - Fixed-time: SUMO 静态配时 (fixed_ts=True, net 自带 8 相位配时);
  - Priority-RL: exp208 best ckpt (γ.95 + 钳位 + ε0.05 + DDQN/Huber/obs三修,
    优先级 Amb:Bus:Car = 5:3:1);
  - 场景: dublin_8std, weekday_11h, num_seconds=3600;
  - 随机性: 各跑 15 个 eval seed (2000–2014), 逐边逐车型取均值。

╔══════════════════════════════════════════════════════════════════════════════╗
║  2. 三个指标的逐边逐车型计算口径 (采集脚本)                                    ║
╚══════════════════════════════════════════════════════════════════════════════╝
  车型归类 (vclass): 按 vehicle type 名 → ambulance / bus / car。
  逐仿真步, 对每辆在网车辆, 取其当前所在 edge (跳过 ":" 路口内部边):

  (a) waiting —— local delta waiting per pass (秒)
      口径 = 车辆【在当前 edge 上新增】的累计等待 (过边/过路口即清零):
        若该车上一步仍在同一 edge: inc = max(0, acc_now − acc_prev), 累加;
        acc = getAccumulatedWaitingTime (SUMO 累计等待);
        车换边 → 基线重置 (local, 不带到下一条边);
        首次进入某 edge 即建 0 条目 (即便全程不等也记 0 → 该边被画, 不漏)。
      聚合: 每条 edge 每车型 = Σ inc / (经过该 edge 的该车型车辆数)
            = "一辆该车型车经过此边时平均新增的本地等待"。

  (b) speed —— 平均速度 (m/s), 时间加权
      每步累加 getSpeed, 记步数; 聚合 = Σspeed / n_steps
      = "该车型在此边的时间平均速度"。

  (c) stopevents —— 平均停车次数 per pass
      停车事件 = 车在【本边】由动(speed≥0.1)转停(speed<0.1)的次数;
      聚合 = Σ停车事件 / (经过该边的该车型车辆数)
      = "一辆该车型车经过此边平均停几次"。

  多 seed 聚合: 对 15 个 seed 的逐边逐车型值取算术平均 (每个 seed 缺该
  (edge,class) 则不计入其平均)。

╔══════════════════════════════════════════════════════════════════════════════╗
║  3. 画图的过滤规则 (去 bias / artifact, 画图脚本)                              ║
╚══════════════════════════════════════════════════════════════════════════════╝
  目标: 只展示 RL 能影响的【真实街道】, 去掉几何 artifact 与少样本偏差。
  R1 internal 边: e.getFunction()=="internal" 的路口内部连接边一律不画
      (非真实街道, 速度/等待是几何 artifact)。
  R2 短连接边: 【保留 ≥2m 的】——真实街道的短边(含 10–20m 连接段)用
      【自身数据】画, 保证线段连续不断开 (短边多数自身有真实车辆数据)。
      仅删 长度<2m 的零长度几何残段 (如 gneE51 L=0.2m, 画出来是孤立
      红点的 artifact, function 为空但非真实街道)。
      [历史: 曾用 MIN_LEN=10/20 删短边→路径断线; 最终改为只删<2m, 其余
       用自身值画, 兼顾"去 artifact 点"与"线段连续"。偏移由±26m减到±10m
       使接头更连续。]
  R3 ambulance 少样本离群边: 手动剔除 {-532427444#2, -532427444#3,
      532427444#7} 的【amb 序列】(均为 St Stephen's Green 西侧瓶颈
      连接边, amb 仅 1–2 车次, 单次卡顿主导, 与 per_visit 全局结论
      矛盾 → 属少样本 bias)。car/bus 在这些边样本充足、真实, 【保留】。
      [残留: 个别 amb 边仍少样本; 彻底解决需采集时存每边车次数, 按
       amb 车次≥N 过滤。当前用手动列表逐条剔除。]

  ★ 关于"短边连续性修补"(原计划 C 方案 vs 实际实现):
      原计划 C: 被过滤的短连接边, 借【下游那一头】边的颜色补画(统一下游)。
      实际实现: 无需借用 —— 30 条短边中 29 条【自身就有真实车辆数据】,
      故直接【用短边自身的实测值】画 (≥2m 即画)。这比借邻边颜色更准确
      (自身=实测, 借用=近似), 且天然连续。"统一用哪一头"的补画逻辑
      因此未启用、也不需要 (不存在"无数据需借邻边"的边, 除<2m残段, 已删)。

╔══════════════════════════════════════════════════════════════════════════════╗
║  4. 着色与版式                                                                 ║
╚══════════════════════════════════════════════════════════════════════════════╝
  连续色标 (colorbar), 非分档:
    waiting / stopevents: 越低越好 → cmap=RdYlGn_r (绿=低=好, 红=高=坏),
        范围 [0, P95];
    speed:                越高越好 → cmap=RdYlGn   (绿=高=好, 红=低=坏),
        范围 [P5, P95]。
    (P5/P95 = 全部边全部车型值的 5/95 百分位, 防离群洗白色标。)
  版式 A (叠线型, fig_edge_<metric>.png): fixed | RL 两子图; 同一图内
    三车型用线型区分 car=实线 / bus=长划线(6,3) / amb=点线(1,3),
    并沿道路法向偏移 car 0 / bus +26m / amb −26m 错开避免遮挡;
    灰色全网底图保证视觉连续。
  版式 B (分车型, fig_edge_<metric>_byclass.png): 3 行(car/bus/amb)
    × 2 列(fixed/RL) 子图; 每子图只画该车型, 实线无偏移, 共享色标。
  improvement 图 (fig_edge_improvement.png): 每边 (fixed−RL), 发散
    色标 RdYlGn (绿=RL改善, 红=RL变差), 对称范围 ±P95(|Δ|)。

╔══════════════════════════════════════════════════════════════════════════════╗
║  6. 当前结果摘要 (15 seed 均值, 全边全车型均值)                                ║
╚══════════════════════════════════════════════════════════════════════════════╝
  speed (m/s, 越高越好):    fixed car 5.62 bus 6.35 amb 6.16
                            RL    car 6.46 bus 7.19 amb 6.60   (全面更快)
  stopevents (次/pass,↓):   fixed car 0.19 bus 0.17 amb 0.21
                            RL    car 0.12 bus 0.07 amb 0.18   (全面更少)
  waiting 见 DUBLIN_VS_FIXEDTIME / 柱状图: RL 全面大幅降低 local 等待。
  注: amb 的逐边数字受少样本影响大 (全网~3-4辆/ep), 优先级结论以
      per_visit 口径 (柱状图: amb 22.33→0.86s) 为准; edge 图主要展示
      car/bus 的空间分布与 RL 的全网改善。

╔══════════════════════════════════════════════════════════════════════════════╗
║  7. 真实局限: RL 在少数瓶颈边的局部退步 (非 artifact, 应写入 limitation)      ║
╚══════════════════════════════════════════════════════════════════════════════╝
  edge 图上 RL 侧残留的几处红/橙【不是 artifact 也不是少样本噪声】, 而是
  RL "局部换全局" 的真实代价, 集中在 St Stephen's Green 西/南侧 2–3 条
  瓶颈边。逐边 fixed→RL 对比 (15 seed 均值, 秒):
    边 38192817 (L=117m, 真实街道, 三车型样本均足):
        car  7.3 → 10.9  (RL +50% 变差)
        bus 12.0 → 11.8  (基本持平)
        amb  1.3 →  8.4  (变差; 含 amb 少样本成分)
    边 -532427444#2 (L=106m):
        car 39.9 / bus 40.0 (fixed/RL 都~40, 真实主干道瓶颈)
        amb fixed 5 → RL 111 (该边 amb 仅1–2车次, 少样本主导, 已剔除amb序列)
  机制: RL 优化全局优先级加权等待, 在个别交叉口为全网让路 → 这几条边
  car(样本足, 退步实打实) 与 amb(少样本, 部分噪声) 局部变差。
  处置原则: 【保留真实数据, 不粉饰】。car/bus 的真实退步如实显示(删之
  即隐藏 RL 未解决的瓶颈, 违反诚信); 仅剔除明确的 amb 少样本离群序列。
  论文建议: 作为 limitation 写明 —— "整体 amb 延误 per-visit 降 96%
  (22.33→0.86s), 但 edge 级分析揭示在 St Stephen's Green 周边 2–3 条
  瓶颈边 RL 为全局优化牺牲了局部 car/amb, 指向未来工作 (per-junction
  优先级约束 / 局部公平性正则)"。
