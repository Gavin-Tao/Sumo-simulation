║  A. 已选定的两条主线                                                          ║

  A1. [选定] MoE-Gcμ: 规则专家 + 学习 gate (用户原创 idea, 2026-07-02 定型)
     架构: 5 个(+1 效率兜底)零训练规则专家, expert-k 优先 k 级
       (系数 5:1); gate = 小网络 (action_space=5/6), 用 BNF 定义的
       priority-avg-waiting 学"此刻该轮到哪个等级"。
     专家规则 (定型, 替代被否的 max-pressure):
       score_k(p) = Σ_c w_c^(k) · [p 服务的 movement 上等级 c 排队车
                    累积等待总和] / n_c,   选 argmax
       = expert-k 自己那版 avg-waiting reward 的一步贪心梯度;
       分母 n_c 使稀疏高等级免疫车流量碾压 (max-pressure 的致命伤,
       count 型压力 1 辆 amb×5 < 20 辆 car×1; 加权重路线 exp157 已证死)。
       理论锚: Van Mieghem generalized-cμ (凸延误成本渐近最优) 的
       discrete-review 版。输入 = φ 已有的逐桶 mean_awt×count, 零新特征。
     卖点四件套: 结构性可解释 (决策=服务哪个等级) | 字典序硬保证一行实现
       (5 级在场 → gate mask 到 expert-5, 接住 G1/GUARANTEE 层) |
       全网统一 5 维动作空间 (跨路口/跨城迁移比内容评分更直接) |
       适配面 = 指甲盖大的 gate (换表只微调 gate, 符合"微调可以"的要求)。
     诚实预期: 原始指标 ≈ 或略低于端到端; 论文主张 = "可忽略代价换
       可验证性+保证+即插适配"; 与 FRAP-enum 不打架 (上界参照 vs
       结构化可部署点, 对照表即论文)。
     必须处理: 与 Dusparic DWL 划界 (TCD 家学; DWL=学习的 per-目标 Q +
       W-value 竞价, 无保证; 本方案=固定规则专家+单 gate+mask 硬保证);
       与已否的 GPI 划界 (专家零训练、语义固定)。
     设计坑: gate 切换时间尺度 (semi-MDP/滞回, 防黄灯风暴) | 专家池
       完备性 (折中相位可能全体错过 → 效率专家兜底)。
     成本: 所有方向里最低, 复用 masked-DQN 全套机器。状态: 待 spec。

  A2. [选定] 风险维度: 等级携带风险态度 (分布式 RL / CVaR per class)
     机制: 高等级类学回报分布 Z (分位数头), 低等级保持均值 Q;
       评分 = Σ低级 w·E[Z] + w_amb·CVaR_α[Z_amb]。
     杀手性质: 分布学一次, α 是部署时旋钮 (mean↔CVaR 连续可调,
       不重训) —— "风险态度 zero-shot", BNF 表扩展为 type→(level, α)。
     motivation 全是自家实测: exp153 PER 尾部灾难 / exp157 加权无效 /
       "永不引用单次 eval amb" 纪律 = amb 问题在尾部不在均值。
     v1 收窄: 1x3 + 普通 DQN + 仅 amb 分位数头 (求和/对决分解与分位数
       不可交换 → 分布头长在相位级, 不进对决分解); CVaR 贪心的时间
       不一致性按 QR-DQN 惯例声明。
     前置: amb 评估功效修复 (eval OD 逐 seed 重采样, 即 forensics S3a)
       —— 没有尾部样本量, 主指标不可测; S3a 升格为方法论组成部分。
     三臂: 均值基线(exp208/211) / 分布头+均值选择(保真) / +CVaR 选择;
       主指标 amb per-visit P95/max, 产出 α 扫出的尾部-均值 Pareto。
     与 A1 会合点: gate 可按 CVaR 选专家 (两线共架构)。状态: 待 spec。

  B1. [喜欢] KAN 可解释性 / 规则蒸馏
     FRAP-enum 的 Q 设计上可分解 (Σg + 对决分), g/s 头换 KAN → 样条长在
     "每等级排队/等待"的人类可读轴上 → 剪枝+符号化 → 接近闭式的规则。
     三层交付: 保真度 | 规则发现 (是否重新发明 max-pressure/Webster/
     preemption 阈值?) | 可认证性 (样条单调性 → "Q 对 amb 排队单调"证书)。
     安全叙事: 应急优先是安全关键系统, 可解释是部署准入不是装饰。
     与 A1 叠加: gate 换 KAN 头 = 可解释调度规则。与 A2 共享"换头"手术。

  B2. [喜欢] LLM→BNF 政策编译器
     BNF 表小、语义化、改表即改行为 → 自然语言政策的完美编译目标
     ("救护车绝对优先; 公交晚点超 5 分钟才优先" → 条件表+约束)。
     与 KAN 闭环: KAN 提规则 → LLM 讲给管理者 → NL 改政策 → 编译回表
     = "可解释↔可配置"回路。定位: LLM 当编译器、RL 当执行器
     (比"LLM 当控制器"流派站得住)。

  B3. [喜欢] 多模态: Luas 电车进场
     网内现成 Harcourt Luas 街道+时刻表。电车=不能变道/不让路的模态,
     暴露等级抽象最弱处 (同级动力学异质), person-based 目标 (1 Luas≈200人)
     最佳引入点。运输期刊向。

  B4. [喜欢] 拓扑库/基础策略: DCC-893 当路口拓扑课程
     几百真实异构路口上训共享策略 → 未见路口 zero-shot ("TSC 基础策略")。
     FRAP 内容评分/A1 的 5 维语义动作空间使之可行 (flat DQN 不行)。
     M5 held-out 迁移是小规模预演。今晚 DCC 场景工作在此回本。

║  C. BNF 运营层 ("优先级运营"框架: 表 = 城市优先级管理的操作界面)              ║

  C1. 优先级通胀曲线: 高等级车占比 5%/20%... → 优先边际价值何时崩塌
     ("人人优先=无人优先"定量版); +作弊鲁棒性 (1% car 自称 4 级)。
     成本最低: 改 route 类型占比做 eval 即可, exp211 checkpoint 现成可测。
  C2. 逆向优先级设计: 城市给 KPI, 双层优化在离散表空间搜最省的表
     (表小而语义化 → 外层便宜到可行, 这本身是 BNF 的结构性益处);
     与 B2 接驳成完整"政策编译"链。
  C3. 优先级预算: 优先分钟数作为配给资源, 上层分配器决定花在哪
     (机制设计×TSC 空白; 表 = 宏观政策与微观控制的 API)。
  C4. 表切换 = 韧性机制: 崩盘前兆检测 (R-campaign 工具链) → 切"事故表"
     → 恢复曲线对比。一张表热切换改变全网行为, 不碰控制器。
  C5. 粒度谱: 类型级→线路级→班次级→单车级 (reward 实现本就 per-vid);
     绿波即服务 / V2I 授权; 收益-粒度曲线。

  D1. 预见维度: bus 到达由 GTFS 提前可知 → anticipatory 优先 (提前腾容量);
     预见窗口价值曲线; 预见价值随等级分布本身是结果。RL 化的
     schedule-aware TSP 是空白。
  D2. 排放维度: 等级按排放等级指派 → 信号优先实现"软低排放区"
     (不禁行不收费); SUMO HBEFA 白送指标; 表=政策工具箱的最政策性展示。
  D3. 感知经济学: 类别观测不完美 (线圈不识类/摄像头覆盖率/V2I 渗透率)
     → "X% 感知投入 → 保留 Y% 优先收益"曲线 (甲方问题, POMDP 实例)。
  D4. 均衡维度: 优先→car 变慢→司机绕路 (Wardrop) → 二阶均衡下优先收益
     余量; duaIterate 设施现成; RL-TSC 几乎无人做二阶效应。计算重。
  D5. 对抗维度: 自动搜索让优先失效的场景 (falsification/红队);
     与 A2 搭档 (CVaR 管已知分布的尾, 对抗生成管分布外)。
  D6. Benchmark 论文: 1x3/1x6/Dublin-18/DCC-893 四尺度 + 评估协议
     (amb 功效、崩盘尾纪律) + 双基线 → 优先级/应急 TSC 无公开基准,
     生态位空白; 研究风险≈0, 引用率通常最高。顺手攒。
