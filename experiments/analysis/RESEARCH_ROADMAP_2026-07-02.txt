  A1. [选定] MoE-Gcμ: 规则专家 + 学习 gate (用户原创 idea; 终版定稿
      2026-07-02 深夜 = "深度-1 MPC 专家", 经三轮迭代收敛)
     部署输入只有两个: net.xml + BNF 表; 其余全为系统常数/物理推导
     ("任意路口任意工况"的 generic 声明, 五条不变性: 拓扑/尺度/负载/
     车种/常数)。
     L1 菜单: enum_phases 极大无冲突组合 (拓扑无关; 菜单无关性: 8std/
       原生相位表同样适用)。
     L2 专家 (6 个, 零训练零参数): expert-k 对每相位 p 算一步预测增量
       选 argmin:
       Δ_k(p) = Σ_c w_c^(k)/max(n_c,1) · [ ①排队∉p: +Δt
         + ②排队∈p 且队位>⌊s·Δt⌋×lanes: +Δt (队尾修正: 绿≠清空)
         + ③行驶中 ETA<Δt (默认仅 c≥4): 红→(Δt−ETA)⁺ 绿→0
           (amb 不停车的来源; /n_c 结构使 car 项可忽略 → 分级是推导) ]
         + ④切相位则新绿前 yellow_time 按红计 (防抖内生, 无滞回参数);
       平局→保持现相位。度量 = time-loss (蠕行也计, amb 正确口径)。
       数据 = traci 逐车直读 (与 reward 同类访问, 零新特征)。
       理论锚: Van Mieghem generalized-cμ 的 discrete-review 一步前瞻版;
       max-pressure 被否原因存档: count 型压力被车流量碾压 (exp157 佐证)。
     L3 gate: 动作空间=6 全网固定词表 (跨路口/跨城迁移之根), obs=现有 φ,
       超参整套继承 exp208, 全网共享。
     L4 保证: presence 触发 (count>0 含行驶中) → mask 至最高在场等级
       专家; 开=字典序硬保证(G1), 关=纯学习; 消融轴。
     退化完备性: 等级缺席(max(n_c,1))/空路口(平局规则)/单相位/过饱和
       (队尾修正)/未知车型(DEFAULT_PRIORITY) 全覆盖。
     消融轴: ETA 项有无 (预期差异集中于 amb 是否停车) | L4 开关 |
       ③分级 vs 全等级。移植成本声明: 新城市 = 枚举工具一跑 + 一张表。

  A2. [选定] 风险维度: 等级携带风险态度 (分布式 RL / CVaR per class)
     机制: 高等级类学回报分布 Z (分位数头), 低等级保持均值 Q;
       评分 = Σ低级 w·E[Z] + w_amb·CVaR_α[Z_amb]。
     杀手性质: 分布学一次, α 是部署时旋钮 (mean↔CVaR 连续可调,
       不重训) —— "风险态度 zero-shot", BNF 表扩展为 type→(level, α)。
     motivation 全是自家实测: exp153 PER 尾部灾难 / exp157 加权无效 /
       "永不引用单次 eval amb" 纪律 = amb 问题在尾部不在均值。
     v1 收窄: 1x3 + 普通 DQN + 仅 amb 分位数头 (求和/对决分解与分位数
       不可交换 → 分布头长在相位级, 不进对决分解); CVaR 贪心的时间
       不一致性按 QR-DQN 惯例声明。
     前置: amb 评估功效修复 (eval OD 逐 seed 重采样, 即 forensics S3a)
       —— 没有尾部样本量, 主指标不可测; S3a 升格为方法论组成部分。
     三臂: 均值基线(exp208/211) / 分布头+均值选择(保真) / +CVaR 选择;
       主指标 amb per-visit P95/max, 产出 α 扫出的尾部-均值 Pareto。
     与 A1 会合点: gate 可按 CVaR 选专家 (两线共架构)。状态: 待 spec。

  B1. [喜欢] KAN 可解释性 / 规则蒸馏 —— 管线已实施 (2026-07-03, c1b653b)
     核心结构红利: FRAP-enum 的聚合 Q=Σg+Σmax对决 是冻结数学, 黑盒只有
     G(27维槽特征)→自需求分 与 S(x_m,x_n,rel)→对决分 两个标量函数 —
     蒸出它们 = 整个控制器闭式化。
     工具三件套 (experiments/tools/kan/, 全部端到端验证过):
       K1 extract_frap_targets.py — eval 协议 rollout 采集 (轴名精确:
          is_green|等级主序 cnt/que/awt×5|down_cnt×5|down_que×5|lane_occ);
          amb 富集靠分层种子 (300s 冒烟片段 10/16 维零方差 → 全量采集
          必须多种子×整集+ε 覆盖, 已诊断记录)
       K2/K3 kan_distill.py — pykan 拟合 + amb 过采样 + --core16;
          --shared-levels 结构检验: G≈b+w·is_green+Σα_l·φ(共享样条)
          → α 即策略内化的有效优先权重 (对账 5:3:1 的 money 实验);
          prune/auto_symbolic; 存 state_dict bundle (pykan lambda 不可 pickle)
       K4 kan_swap_eval.py — 蒸馏件塞回冻结聚合, 按 rel 类批量前向
          (静态冲突对预计算), 动作一致率 + 闭环 reward
     四问预注册: awt 样条凸性(Gcμ 再发现?) | 下游折价(spillback 意识?) |
       merge vs crossing 公式差(四类之争的实证答案) | is_green 滞回。
     后端决策: pykan (剪枝/符号/画图工具链=交付物本身); efficient-KAN
       留给训练内 KAN 头 (MoE gate 直训, Option A) — 用户问询后定案。
     全量运行命令 (等训练链空闲): K1 --seeds 123,2000-2009 --eps-seeds
       3000,3001 (全 3600s) → K2 各 target steps 200 → K4 --seeds 多种子。
     与 A1 叠加: gate 换 KAN 头 = 可解释调度规则。与 A2 共享"换头"手术。

  C1. 优先级通胀曲线: 高等级车占比 5%/20%... → 优先边际价值何时崩塌
     ("人人优先=无人优先"定量版); +作弊鲁棒性 (1% car 自称 4 级)。
     成本最低: 改 route 类型占比做 eval 即可, exp211 checkpoint 现成可测。
  C2. 逆向优先级设计: 城市给 KPI, 双层优化在离散表空间搜最省的表
     (表小而语义化 → 外层便宜到可行, 这本身是 BNF 的结构性益处);
     与 B2 接驳成完整"政策编译"链。
  C3. 优先级预算: 优先分钟数作为配给资源, 上层分配器决定花在哪
     (机制设计×TSC 空白; 表 = 宏观政策与微观控制的 API)。
  C4. 表切换 = 韧性机制: 崩盘前兆检测 (R-campaign 工具链) → 切"事故表"
     → 恢复曲线对比。一张表热切换改变全网行为, 不碰控制器。
  C5. 粒度谱: 类型级→线路级→班次级→单车级 (reward 实现本就 per-vid);
     绿波即服务 / V2I 授权; 收益-粒度曲线。
