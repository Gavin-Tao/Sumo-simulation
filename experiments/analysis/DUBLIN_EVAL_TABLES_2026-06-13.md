1. best真伪: 仅 exp208 真收敛(eval尾段std=2.1); 205/206/207 的best是震荡峰值(尾段std 180~349),
   数值看着好(−12~−14)实为赌运气 → 性能比较只信 exp208, 且只信尾段(表2/4)不信best(表1/3)。
2. 优先级阶梯(fair口径 per_visit, exp208): amb < bus < car 完美成立无反转。
3. floor有害: 206/207(带floor)的amb尾段std爆炸(±21.6/±3.9), 远不如208(±0.7)。
4. γ.95(208) > γ.99(205): 208所有指标std小一个量级。

## 读表要点
- 表1/3 (BEST): 四臂数值接近, 但仅208可信(其余best=震荡谷底), 不要据此排名。
- 表2/4 (尾段20): 看std → 208全部小一量级=真收敛; 206/207 std巨大=未收敛。
- ★FAIR反转判定(表4 avg_stopped_time_per_visit, exp208尾段):
  amb 0.86 < bus 1.31 < car 4.95 → 阶梯成立, amb每路口停驶仅car的1/5.8。
  stop_events_per_visit 同向(amb 0.14 ≤ bus 0.18 < car 0.60), xts_avg_speed amb最高。
- ⚠不公平口径(avg_stopped_time 全程累计): amb穿越多路口会偏高, 不用于判反转。
- amb样本n≈3/ep, 即使尾段20平均std仍大(±0.7~21.6), amb绝对值需≥50seed才精确;
  但阶梯方向在208上稳健。
- car恶化: 208的car比固定配时差(per_visit 4.95 vs 固定2.18), 是优先级的trade-off
  (牺牲car保amb/bus), 详见 DUBLIN priority对照(exp210跑完后补)。
