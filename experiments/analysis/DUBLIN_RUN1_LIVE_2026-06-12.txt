    exp192 (clip):   loss 0.2→1739 (升); eval 剧烈双峰震荡:
                     −409,−356,−50.8,−73.5,【−5926,−5638】,−1397,...,−635

  ── 5.1 回答一: loss 上升本身大部分是【量纲现象】, 不是发散信号 ──────────────
    loss = MSE, 单位是 Q²。Dublin 拥堵态每步 r ≈ −10~−50 → Q ≈ r/(1−γ)
    ≈ −1000~−5000。对 |Q|~1000 的状态, 5% 的 TD 误差 → MSE ≈ 2500。
    所以 Dublin 的【健康 loss 地板就在千位数】, 不能拿 1x3 的 0.1 比。
    而且训练早期 Q 从 0 向 −1000s 自举爬坡, 爬坡期 target 持续下移 →
    TD 误差持续大 → loss 先升后稳是【预期行为】。判发散看的不是
    "loss 在升", 而是 "loss 升破 1e5 不回头 + eval 崩死不复" (run1 是
    loss 555 万 + eval 永久 −4000, 那才是发散)。

  ── 5.2 回答二: 真正不对的是 eval 的双峰震荡 —— 悬崖动力学 ──────────────────
    eval 在 −50 (近最优!) 和 −5900 (网络性瘫痪) 之间跳。机制:
    11h 场景 4835 veh/h 接近关键路口饱和, 存在"悬崖": 几分钟的坏控制
    → 溢回级联 → 3600s episode 内不可恢复的全网拥堵 → accumulated
    waiting 线性累积 → episode 奖励 −5000。策略在悬崖边缘, 每次 eval
    落在哪边近乎二值。Dublin 奖励跨度 −25~−9000 = 360 倍, 1x3 只有
    ~−30±20 —— Q 函数要同时表征两个 regime, 这是曲线"感觉不对"的根源。

  ── 5.3 回答三: 是 route/net 的问题吗? —— 基本不是, 证据三条 ────────────────
    ① 场景本身验证过: 固定配时下 3600s 全程 0 teleport、4835 辆全部
       完成 —— 需求是可服务的, net 无结构性死锁;
    ② 任务可学且上限存在: run1 和新跑都反复摸到 −24~−50 (近最优) ——
       net/route/mask/obs 链路全部工作;
    ③ 失败模式是"控制诱导的拥堵"——任何接近真实负载的场景都有, 这是
       任务难度不是数据 bug。
    但两个【设计选择】确实把悬崖推近了 (诚实记录, 非 bug):
    a) B5 保护相位化 (去 'g') → 路口容量余量变小;
    b) 校准刻意贴近真实流量 → 关键路口本就接近饱和。

  ── 5.4 结构性嫌疑人: capacity 50k 的"缓冲死亡螺旋" ─────────────────────────
    50k transitions = 仅 3.8 个 Dublin episode 的记忆 (1x3 是 83 个)。
    连续 2-3 个瘫痪 episode 后, buffer 里【全是瘫痪态数据】, 自由流
    经验被挤出 → Q 只在灾难区训练 → 策略找不到回去的路 → 下个
    episode 还是瘫 (正反馈)。1x3 中坏 episode 被 80 个好 episode 稀释,
    Dublin 没有这个稀释。当前 192 的震荡模式与该机制一致 [推测]。
    注: 我此前的 capacity 300k 适配正是冲着它, 已按用户对照哲学撤销 —
    是否恢复由证据裁决 (见 5.5 判据)。

  ── 5.5 处置建议 (不执行, 等用户指令) ───────────────────────────────────────
    观察点 (ep~150-250): ① 198 (无clip) loss 是否爆破 1e5 → 验证 clip
    必要性 (run1 在 ep~240 到 555 万); ② 192 (clip) 能否脱离震荡向
    −100 内收敛。
    若 192 持续震荡不收敛, 杠杆按优先级:
    L1 capacity 50k→300k (针对 5.4 死亡螺旋, 单变量重跑 192);
    L2 Huber loss 或奖励缩放 r/30 (针对悬崖态的爆炸性 TD 误差);
    L3 课程式: 先 02h 自由流预训 → 11h (利用现成三场景);
    L4 需求 0.9× 评估场景变体 (把悬崖推远, 论文需注明)。
    另: exp197 (colight, 标准 lr 1e-3 + clip) 早期健康 (loss 有界、
    eval 改善) —— 如果走完全程收敛, 则 colight 之前两败的元凶锁定为
    【lr 3e-4 过低 + (run1) 无 clip】, 而非结构问题。
